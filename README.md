# SpendWise – Budget Tracker

## Project Description
SpendWise is a simple budget-tracking application designed to help users manage their monthly budgets, record expenses, and calculate their remaining balance.

## JavaScript Concepts Implemented

### 1. Variables
The application uses JavaScript variables such as `budget`, `expenses`, and `remainingBalance` to store budgeting information.

### 2. User Input
The `prompt()` function collects the user's monthly budget and total expenses. The `Number()` function converts the input into numerical values.

### 3. Budget Calculations
The application subtracts total expenses from the monthly budget to determine the remaining balance.

### 4. Functions
A reusable function called `calculateBalance()` performs the budget calculation. This keeps the code organized and makes it easier to reuse.

### 5. Displaying Results
The `console.log()` method displays the monthly budget, total expenses, and remaining balance in the browser console.

## How to Run the Project
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter your monthly budget when prompted.
4. Enter your total expenses.
5. Open the browser developer console to view the results.
